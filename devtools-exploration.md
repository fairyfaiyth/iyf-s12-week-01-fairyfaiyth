# DevTools Exploration

## Website 1: https://example.com
1. **HTML tags used on the page:** `html`, `head`, `meta`, `title`, `body`, `div`, `h1`, `p`, `a`, `style`
2. **Page title:** Example Domain
3. **Heading count:** 1 heading (an `<h1>` element)

## Website 2: https://mozilla.org
1. **Navigation menu wrapping tag:** `<nav>`
2. **Search bar structure:** An `<input type="search">` element wrapped inside a `<form>` element acting as a search container.
3. **Link hover styles:** Uses CSS transitions changing text color hues and text decoration (underline transitions).

## Website 3: https://github.com
1. **5 different HTML elements:** `<header>`, `<main>`, `<button>`, `<svg>`, `<footer>`
2. **Form element and inputs:** The repository search form utilizes `<input type="text">` bound with specific UI layout autocomplete behaviors.
